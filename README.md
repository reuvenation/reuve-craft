# ГРАНЬ — лендинг журнального столика

Минималистичный одностраничник для дизайнерского журнального столика
(массив дуба + закалённое стекло). Белый фон, плотный гротеск, выноски-линии
от изделия — по референсам TAKT / ASTER.

## Стек

- **Next.js 16** (App Router, Turbopack) + **TypeScript**
- **Tailwind CSS 4** — токены темы в `src/app/globals.css`
- **Motion** (`motion/react`) — появления, параллакс, отрисовка линий-выносок
- **Zod 4** — валидация заявки на сервере

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # прод-сборка
npm start
```

## Что где

| Файл | Зачем |
| --- | --- |
| `src/lib/site.ts` | бренд, телефон, размеры столика, отделки, мессенджеры — единая точка правды |
| `src/components/hero.tsx` | первый экран: заголовок, кадр 3/4, форма справа |

| `src/components/v2/` | компоненты только для `/v2`: `hero-v2`, `lead-form-v2`, `figure-v2`, `gallery-v2` |

## Два варианта

На одном сервере живут оба: `/` — первый вариант, `/v2` — второй, более
минималистичный (форма без карточки, статичный кадр с выносками, три фото и
перечень отделок; ни одного переключателя). Компоненты не пересекаются:
`v2` использует общие `lib/`, `icons.tsx` и API заявок, но свою вёрстку.
Страница `/v2` закрыта от индексации (`robots: index: false`).

## Заявки

`POST /api/lead` проверяет данные, режет ботов (honeypot + лимит 5 заявок
на IP за 10 минут) и пишет строку в `data/leads.jsonl` (папка в `.gitignore`).
Если заданы `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` — дублирует заявку в
Telegram. Переменные — см. `.env.example`.

## Выноски на изображении

Координаты точек привязки заданы в долях кадра 3/4 (`callouts` в
`construction.tsx`) и пересчитываются в систему `viewBox 1100 × 460`.
Кадры светлого дуба и тёмного ореха сняты в одной раскадровке, поэтому
выноски совпадают при смене отделки. Если менять картинку — пересчитать
`anchor` (доли ширины/высоты изображения).

## SEO

- `<h1>` с ключевым запросом, микроразметка Product (JSON-LD) на главной
- метатеги + Open Graph в `src/app/layout.tsx`, `robots.ts`, `sitemap.ts`
- боевой домен задаётся через `NEXT_PUBLIC_SITE_URL`
